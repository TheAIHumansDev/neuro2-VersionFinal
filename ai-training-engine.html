Cómo funciona
  • 1. Se toman los fragmentos de tus documentos indexados y, si existe, la síntesis del núcleo.
  • 2. Tu IA detecta las intenciones más probables del público y escribe cada flujo con la voz de tu avatar.
  • 3. Cada paso trae opciones de respuesta que llevan al siguiente paso, a un cierre o a un humano.
  • 4. Puedes probar un flujo en el playground, exportarlo en JSON o agregarlo al dataset de entrenamiento.

// Se ejecuta cuando el usuario habla con el avatar
async function queryAvatarCore(userSpeech, sessionId) {
  const res = await fetch(`${TU_BACKEND}/v1/avatar/query`, {
    method: "POST",
    headers: { "Authorization": `Bearer ${AVATAR_API_KEY}`, "Content-Type": "application/json" },
    body: JSON.stringify({ query: userSpeech, session_id: sessionId, mode: "rag_only" })
  });
  const data = await res.json();
  // data.response.text → motor de voz (TTS); avatar.emotion / gesture → animación
  avatarEngine.speak(data.response.text, data.response.avatar);
  return data;
}
2 Recorrer un flujo generado
JavaScript · motor de flujos
// flows = contenido exportado desde "Flujos conversacionales"
function runFlow(flow, stepId = flow.pasos[0].id) {
  const step = flow.pasos.find(p => p.id === stepId);
  avatarEngine.speak(step.bot);
  showOptions(step.opciones, opt => {
    if (opt.siguiente === "fin") return endConversation();
    if (opt.siguiente === "humano") return handoffToHuman();
    runFlow(flow, opt.siguiente);
  });
}

// Guarda tu clave en Configuración del proyecto → Script Properties → ANTHROPIC_API_KEY
function doPost(e) {
  const body = JSON.parse(e.postData.contents);
  const apiKey = PropertiesService.getScriptProperties().getProperty("ANTHROPIC_API_KEY");
  // Valida y descuenta créditos del usuario (ej. en un Google Sheet) antes de responder
  const res = UrlFetchApp.fetch("https://api.anthropic.com/v1/messages", {
    method: "POST",
    headers: { "x-api-key": apiKey, "anthropic-version": "2023-06-01", "Content-Type": "application/json" },
    payload: JSON.stringify({ model: body.model || "claude-sonnet-5", max_tokens: body.max_tokens || 500, system: body.system, messages: body.messages })
  });
  return ContentService.createTextOutput(res.getContentText()).setMimeType(ContentService.MimeType.JSON);
}

📡
¿Qué es un feed RSS?
Un enlace que un blog o medio publica con sus artículos más recientes en un formato legible por máquinas. El motor lo revisa cada cierto tiempo y trae los títulos nuevos.
🔗
¿Qué es una API?
La puerta que un servicio ofrece para que otros programas pidan sus datos. Necesitas una clave (API Key) que el proveedor te entrega al registrarte.
✅
¿Qué debo hacer?
Copia la URL del feed o crea una cuenta de desarrollador en el servicio (ej. NewsAPI), pégala abajo y elige la frecuencia de sincronización.

function enviarReporteAvatar() {
  const api = PropertiesService.getScriptProperties().getProperty("IA_TRAININGS_API_KEY");
  const res = UrlFetchApp.fetch(`${TU_BACKEND}/v1/report`, {
    method: "POST",
    headers: { "Authorization": `Bearer ${api}`, "Content-Type": "application/json" },
    payload: JSON.stringify({ date: hoy() })
  });
  const data = JSON.parse(res.getContentText());
  GmailApp.sendEmail("equipo@tuempresa.com", `✦ Reporte del avatar · ${hoy()}`, "", { htmlBody: buildHTML(data), name: "IA Trainings" });
}
function hoy() { return Utilities.formatDate(new Date(), "America/Costa_Rica", "dd/MM/yyyy"); }
